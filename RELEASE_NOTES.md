# LocalSave 2.8.1 — Office detection fix

- Finds open Word, Excel and PowerPoint documents through their desktop windows as well as the registered Office app.
- Distinguishes a closed app from a running app whose documents are temporarily unavailable.
- Keeps pending save warnings while access is incomplete.

Exit LocalSave from the tray and run the new Setup. Your settings carry over. This is an unsigned preview. LocalSave users with preview checks enabled can receive an update notification.
